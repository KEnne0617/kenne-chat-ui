# kenne-chat-ui
This is a desktop chat UI project. It looks simple, but it has lots of details and feels complete. Built with Python and PySide6. It's just one file. Want something simple, stylish, and convenient? Try it.

## Download

Prebuilt Windows build, no Python required: **[KEnne.exe](https://github.com/KEnne0617/kenne-chat-ui/releases/latest/download/KEnne.exe)**

Run from source:

```bash
pip install PySide6
python src/KEnne_chat_UI.py
```

Keys: Enter sends, Shift+Enter or Ctrl+Enter adds a new line. Drag the top edge of the input box to resize it.
